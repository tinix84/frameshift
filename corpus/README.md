# Exemplar corpus

These worked cases are the fastest way to understand FrameShift's intended
behaviour. Each directory is self-contained: read its narrative, then inspect
the intake, citation, reference result, and harness expectations.

## Available exemplars

- [`kafka-in-disguise`](kafka-in-disguise/) — a negative starting case: a
  technology request with no owned outcome. The engine asks for the missing
  outcome before optimising.
- [`battery-cost-structure`](battery-cost-structure/) — a component cost
  request reframed toward product cost structure and an owned cost target.
- [`elevator-wait-complaint`](elevator-wait-complaint/) — a speed request
  reframed toward perceived wait and the experience being measured.
- [`headphones-for-everyone`](headphones-for-everyone/) — a purchasing request
  that surfaces the absent meeting-scheduling decision owner.
