# Architecture decision records

ADRs capture durable, cross-cutting decisions. Status values are `proposed`, `accepted`, `deprecated`, or `superseded`. The decision text of an accepted ADR is not edited to change history; when a later ADR overtakes it, its `Status` line is updated to point at the ADR that did so, and the extent is stated there when the supersession is partial.
