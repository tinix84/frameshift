# Prompt release 2.0.0

This release adds structured task-frame prompts for the bounded reasoning-input
contract in #168. Each prompt declares portable maintainer identity, accepted
artifact types, a 1,048,576-byte aggregate ceiling, and JSON depth 64.

The problem-framing prompt separates all eight task-frame parts. The repair
prompt preserves the one-attempt, shape-only rule and receives only validation
errors and invalid structured output. Version 1 prompt files and their release
record remain unchanged for attribution of earlier results.

Publication policy: [ADR-0017](../../docs/adr/0017-published-prompt-identities.md).
